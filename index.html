📖 .shml 独自スクリプト言語の書き方

                    

                        
# コメント : 先頭に # を書くとメモ（無視）になります

                        
_ / __ : _（1つ）でブロック区切り、__（2つ）でスクリプト終了

                        
~ (複数行指定) : ("1~5") や (*"元の文字","10~25")-("新文字") のように行範囲を複数指定可能！

                        
[change] : *(置き換え) / +(追加: {button}, {file}) / =(消去) / /(移動)

                        
対応プログラミング言語ブロック :
                            [javascript] /
                            [python] /
                            [java] /
                            [php] /
                            [html]
